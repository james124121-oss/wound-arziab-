# WoundMeasure AI v8

New in v8:
- Search previous patient by MRN or Patient ID from Google Drive
- List previous assessments
- Open a previous assessment and restore patient/wound fields
- Restore previous wound/granulation measurements as baseline
- Load the latest prior wound photograph as Ghost Overlay
- Continue directly into standardized follow-up photography

Also included from previous versions:
- Patient OCR intake
- Wound and granulation measurement
- Serial wound area reduction
- Burn-depth assistant
- TBSA calculator
- PDF / Word / Excel export
- Anonymized research Excel
- Google Drive backup

## Upgrade Apps Script
Replace your existing Apps Script code with the included `google_apps_script.gs`,
then redeploy the Web App. If Google gives you a new deployment URL, paste it into the app.

Important:
This remains an MVP. Identifiable patient data require institutional privacy/security review,
authentication, authorization, audit logging and an approved data-retention policy.
